# InteriorFun
Database & Store Management System
A web-based database management and tracking application designed for inventory, invoicing, and order fulfillment workflows.

## 🛠️ Tech Stack
* **Frontend/Backend:** PHP, HTML, CSS
* **Database Management:** SQL (MySQL / MariaDB via phpMyAdmin)
* **Design & Modeling:** Draw.io (ER Diagrams & Use Case flows)

## 📂 Key Features
* **Role-Based Dashboards:** Separate interfaces for managers, employees, supervisors, and customers.
* **Order Tracking:** Real-time tracking and status updates for customer and supplier orders.
* **Inventory Management:** Low stock alerts, product additions, and supplier receipts.
